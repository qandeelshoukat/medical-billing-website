# medical-billing-website
A responsive and user-friendly medical billing website built using HTML, CSS, and JavaScript. This project presents healthcare billing services with a clean interface and provides easy communication options through email and WhatsApp integration. It is designed to deliver a simple yet effective digital presence for medical billing solutions

## Features
- Responsive design for all devices  
- Clean and professional UI  
- Medical billing services overview  
- Email contact integration  
- WhatsApp direct chat option  

## Technologies
HTML5, CSS3, JavaScript
